# AnnyBody reference

This is the `fullbody_default` reference exported by `burn_human` using Anny and its
MakeHuman/MPFB2 body data. The body assets are released under [CC0](CC0.md).
Compression preserves every tensor and the original rig metadata.

The SHA-256 of the decompressed safetensors file is
`dc2db51d9ccac2a50664f99e6843f54f319f23ca5ad50d26b6648f3764261472`.
The original bundle can be recovered with `zstd -d fullbody_default.safetensors.zst`.
